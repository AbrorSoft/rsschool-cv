About me

Frontend developer with 2.5+ years of commercial experience designing and building scalable web applications on Angular.

My strongest ground is fintech and complex administrative systems: interfaces integrated with major commercial banks, dashboards that stay usable when a table holds thousands of rows, and deeply nested reactive forms that still validate predictably. I have also worked with geo services (Yandex Maps API), rich-text editing and real-time content updates, and I regularly profile and optimise interface performance instead of guessing where the cost is.

Priorities in work: readable code over clever code, explicit error and empty states, small reviewable pull requests, and honest estimates. I prefer owning a feature end to end — from the Figma file and API contract to the production release and the bug reports that follow.

Goals for the next stage: grow from strong middle into senior frontend engineer — deeper application architecture and state management, disciplined unit and e2e testing, measurable performance budgets — and share that with juniors through code review. I am currently strengthening my fundamentals through the RS School frontend course and open to roles where engineering culture and review are taken seriously.
